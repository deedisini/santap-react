# Matriks Keterlacakan Kebutuhan SANTAP (Requirement Traceability Matrix)

Dokumen ini memetakan keterlacakan menyeluruh (*end-to-end traceability*) dari seluruh kebutuhan fungsional (FR-01 s/d FR-20), kebutuhan non-fungsional (NFR-01 s/d NFR-07), use case (UC-01 s/d UC-11), diagram pemodelan UML (Use Case, Activity, Sequence, Class, ERD), implementasi kode sumber (komponen React, modul server, aturan keamanan), layar antarmuka (L-01 s/d L-06), hingga kasus pengujian otomatis (*test suite*).

Acuan teknis utama: [SRS Final](srs/SANTAP_SRS_FINAL.md), [Kamus Data](KAMUS_DATA.md), [Laporan Pengujian](PENGUJIAN.md), dan [Checklist Rubrik Final](../Penilaian/CHECKLIST_FINAL.md).

## 4. Status keterlacakan dan penerimaan

Terdapat **13 Must, 5 Should, dan 2 Could**. Matriks menunjukkan hubungan artefak dan cakupan test, bukan klaim semua kebutuhan telah diterima pengguna. ID FINAL pada SRS final berbeda namespace dengan ELIS/usulan v1.2 historis.

Test memakai mock/JSDOM. Login Firebase, kamera, unduh PNG, receipt melalui kamera, simpan konfigurasi ke layanan nyata, penerimaan email/push perangkat, dan beban kampus belum diuji. Pembaruan profil memiliki regresi fungsi pada profiles.test.js; pengujian UI Admin dengan database nyata masih perlu dilakukan. Penegakan rules Firestore belum diuji dengan emulator. Lihat expected/actual per UC dalam [laporan pengujian](PENGUJIAN.md).

Kolom model memetakan desain domain; tabel/koleksi diimplementasikan sebagaimana [kamus data](KAMUS_DATA.md). Enam layar mencakup panel fungsional dalam halaman yang sama. Tidak ada klaim enam URL terpisah atau semua NFR telah lulus.
