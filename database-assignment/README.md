# SANTAP Database Assignment

This folder preserves the MySQL/MariaDB implementation that was separated from the SANTAP System Analysis & Design application.

It is not used by the main React/Firebase application. The SANTAP app uses Firebase Authentication and Cloud Firestore for operational data, while this folder contains the relational database material for the separate Database class assignment.

Contents include the relational schema, seed/reset scripts, v1.2 migration, SQL operations/API modules, the physical ERD, and the original MySQL setup guide.

Run these files independently from the main app. Do not enable SQL mode or add the database-assignment files back into the SANTAP runtime unless the two projects are intentionally reunited.
